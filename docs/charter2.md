# Устав проекта: Аналитика рынка аренды жилья в Магнитогорске
##  Цели и критерии успеха
**Главная цель:** к финалу семестра создать воспроизводимый аналитический сервис по аренде жилья в Магнитогорске сроком от 1 месяца, который помогает приезжему работнику завода выбрать район и квартиру по критериям «цена — дорога до предприятия — инфраструктура — условия заселения», а собственнику — обосновать ставку.

|---|---|---|---|---|
| Создать сервис по аренде от 1 мес. для заводчан | Готовность обязательных функций (сбор, расчёт, карта, индекс, экспорт) | 0% | 100% | Финал семестра |
| Собрать датасет объявлений об аренде от 1 месяца | Число очищенных уникальных объявлений / доля посуточной | 0 / — | ≥100 / ≤5% | ЛР 3 |

**Подцели по SMART:**

1. **Собрать датасет.** Показатель: число уникальных объявлений об аренде от 1 мес. Сейчас: 0. Хотим: ≥100, доля посуточной ≤5%. Срок: ЛР 3. Проверка: фильтр по сроку + ручная валидация.
2. **Рассчитать метрики.** Показатель: число метрик (медианная ставка по комнатности, по районам, близость к предприятиям, доля «с мебелью», типичный срок). Сейчас: 0. Хотим: ≥10, покрытие 100% районов. Срок: ЛР 4.
3. **Индекс доступности.** Показатель: доля районов с рассчитанным индексом (ставка/зарплата + время до завода). Сейчас: 0%. Хотим: 100%, отдельно — районы «доступно + ≤30 мин до завода». Срок: ЛР 5.
4. **Воспроизводимость и сценарии.** Показатель: запуск одной командой / число сценариев / отчёт. Сейчас: нет / 0 / нет. Хотим: да / 2 / да. Срок: ЛР 6.

### Критерии успеха (Definition of Done)
- Пайплайн запускается одной командой без ручных правок.
- Датасет ≥100 объявлений, по каждому — адрес/район, площадь, комнатность, ставка руб./мес., срок аренды.
- В отчёте есть минимум 10 метрик и индекс доступности по всем районам.
- Два сценария использования: «выбор жилья работником» и «обоснование ставки собственником».
