# Устав проекта: Аналитика рынка аренды жилья в Магнитогорске

Версия 1.0 · Дата: 2026-10-10 · Авторы: Вячеслав С., Илюза Б., Альберт Б. · Статус: на согласовании

## 1. Проблема и ценность

У иногородних сотрудников Магнитогорска (вахтовиков, молодых специалистов, работников ММК) есть проблема нехватки дешёвого и удобного жилья в аренду, из-за которой люди тратят на дорогу до работы часы и переплачивают за съём. Программа компенсации найма от ММК (увеличена с 10 000 до 20 000 руб.) не решает проблему: разброс цен по районам огромный — в Орджоникидзевском однушка стоит 17 000 руб., в Правобережном — от 20 000 до 45 000 руб. Компенсация в 20 000 руб. покрывает аренду только в дешёвых районах.

Предлагаемое решение — аналитический сервис по длительной аренде (от 1 месяца) для приезжих работников заводов: реальные ставки с Циан и Авито, метрики по районам, индекс доступности «ставка/зарплата + время до проходной», сценарии для работника и для кадровой службы ММК.

Подробности: [business-case.md](business-case.md).

## 2. Цели и критерии успеха

**Главная цель:** к финалу семестра создать воспроизводимый аналитический сервис по аренде жилья в Магнитогорске сроком от 1 месяца, который помогает приезжему работнику завода выбрать район и квартиру по критериям «цена — дорога до предприятия — инфраструктура — условия заселения», а собственнику — обосновать ставку.

| Цель | Показатель | Сейчас | Хотим | Срок |
|---|---|---|---|---|
| Создать сервис по аренде от 1 мес. для заводчан | Готовность обязательных функций (сбор, расчёт, карта, индекс, экспорт) | 0% | 100% | Финал семестра |
| Собрать датасет объявлений об аренде от 1 месяца | Число очищенных уникальных объявлений / доля посуточной | 0 / — | ≥100 / ≤5% | ЛР 3 |
| Рассчитать метрики под профиль приезжего заводчанина | Число метрик / покрытие районов | 0 / 0% | ≥10 / 100% | ЛР 4 |
| Построить индекс доступности (ставка/зарплата + время до завода) | Доля районов с индексом | 0% | 100% | ЛР 5 |
| Обеспечить воспроизводимость и сценарии использования | Запуск одной командой / сценарии / отчёт | нет / 0 / нет | да / 2 / да | ЛР 6 |

**Подцели по SMART:**

1. **Собрать датасет.** Показатель: число уникальных объявлений об аренде от 1 мес. Сейчас: 0. Хотим: ≥100, доля посуточной ≤5%. Срок: ЛР 3. Проверка: фильтр по сроку + ручная валидация.
2. **Рассчитать метрики.** Показатель: число метрик (медианная ставка по комнатности, по районам, близость к предприятиям, доля «с мебелью», типичный срок). Сейчас: 0. Хотим: ≥10, покрытие 100% районов. Срок: ЛР 4.
3. **Индекс доступности.** Показатель: доля районов с рассчитанным индексом (ставка/зарплата + время до завода). Сейчас: 0%. Хотим: 100%, отдельно — районы «доступно + ≤30 мин до завода». Срок: ЛР 5.
4. **Воспроизводимость и сценарии.** Показатель: запуск одной командой / число сценариев / отчёт. Сейчас: нет / 0 / нет. Хотим: да / 2 / да. Срок: ЛР 6.

**Критерии успеха (Definition of Done):**

- Пайплайн запускается одной командой без ручных правок.
- Датасет ≥100 объявлений, по каждому — адрес/район, площадь, комнатность, ставка руб./мес., срок аренды.
- В отчёте есть минимум 10 метрик и индекс доступности по всем районам.
- Два сценария использования: «выбор жилья работником» и «обоснование ставки собственником».

## 3. Границы проекта

**Входит:**

- Сбор объявлений о длительной аренде (от 1 месяца) по Магнитогорску с открытых источников (Циан, Авито).
- Очистка и дедупликация датасета (≥100 записей).
- Расчёт метрик: медианные ставки по комнатности и по районам, доля «с мебелью», типичный срок аренды.
- Индекс доступности: доля медианной ставки в медианной зарплате работника завода + время в пути до проходной ММК.
- Два сценария использования: «выбор жилья работником» и «обоснование ставки собственником».
- Воспроизводимый пайплайн (запуск одной командой) и итоговый отчёт.

**Не входит:**

- Посуточная аренда и гостиницы.
- Купля-продажа жилья.
- Юридическое сопровождение сделки.
- Оценка конкретных квартир (только агрегированные метрики по районам).
- Интеграция с внутренними системами ММК и кадровыми базами.

## 4. Допущения и ограничения

| Тип | Описание | Как проверяем |
|---|---|---|
| Допущение | Объявления на Циан и Авито отражают реальные рыночные ставки длительной аренды | Сверяем медианы с публикациями в СМИ по Магнитогорску; ручная валидация 10% выборки |
| Допущение | Компенсация ММК 20 000 руб. — актуальная величина на период проекта | Ссылка на официальный источник / новость ММК |
| Допущение | Время до проходной можно оценить по расстоянию и картам (пешком / транспорт) | Сверка на 5 адресах с картами |
| Ограничение | Объём выборки — ≥100 объявлений | Меньше 100 → метрики по районам нестабильны; помечаем «мало данных» |
| Ограничение | Срок проекта — один семестр | Вехи привязаны к ЛР 1–6 |
| Ограничение | Только открытые данные, без платных API | Проверяем, что источник доступен без подписки |
