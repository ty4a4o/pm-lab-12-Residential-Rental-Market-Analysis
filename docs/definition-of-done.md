# Definition of Ready и Definition of Done

## Definition of Ready (задача готова к работе)

Задачу можно брать в спринт, если:

- У задачи есть четкая цель и понятные критерии приёмки (что именно должно получиться)
- Задача привязана к одному из эпиков (E1–E6 из WBS) и имеет приоритет (MoSCoW).
- Известно, какие данные нужны для работы (например, выгрузка объявлений с Авито) и где они лежат.
- Оценка задачи не превышает 16 часов (чтобы один человек мог выполнить её за один двухнедельный спринт).
- Зависимости сняты (например, парсер написан до того, как мы начали очищать данные) или известно, когда они будут сняты.

## Definition of Done (задача выполнена)

### Для любой задачи

- Выполнены все критерии приёмки, описанные в задаче.
- Изменения влиты в ветку `main` через Pull Request.
- PR одобрен (Approved) хотя бы одним другим участником команды (так как нас 3, кросс-ревью обязательно).
- Автопроверки (GitHub Actions) прошли без ошибок.
- Обновлена документация (README, описание данных, комментарии в коде), если изменилось поведение.

### Для задач с данными

- Сырые данные (raw) не попали в Git (добавлены в `.gitignore`), чтобы не раздувать репозиторий.
- В реестре источников (`data/sources.md`) зафиксирована дата выгрузки и ссылка.
- Скрипт очистки или ноутбук запускается сверху вниз без ошибок.
- Все цены приведены к единой единице измерения (рубли за месяц).

### Для пользовательских историй

- Сценарий использования проверен: система корректно фильтрует объявления по сроку (от 1 мес.) и бюджету.
- Есть визуализация (карта или график) с легендой, подписью источника данных и датой сбора.
- Интерфейс корректно отображается на экране шириной 360 px (проверено в DevTools).
